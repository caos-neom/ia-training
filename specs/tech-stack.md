# Stack Tecnologica

## Padrao inicial

- Next.js para a aplicacao web.
- TypeScript como linguagem principal.
- SQLite como banco de dados inicial.

## Requisitos de produto

- Interface responsiva para dispositivos moveis.
- Compatibilidade com navegadores modernos.
- Catalogo de cursos tecnicos e respectivas matrizes curriculares.
- Area com login para cadastrar noticias exibidas na pagina principal.

## Decisoes em aberto

- Bibliotecas de interface, acesso a dados e autenticacao serao definidas durante a implementacao.
- SQLite e uma escolha inicial, sujeita a revisao conforme as necessidades de implantacao.
